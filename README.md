# Have You Tried Turning It Off?

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b)

One funny line a hopeless tech support agent says to a desperate customer, for the [make.fun competition "Have You Tried Turning It Off?"](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

> No worries at all, let's restart your router, your laptop and, if you have a minute, your entire career before that big meeting.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This reads `line.txt`, validates it (one line, 1–199 characters), and writes it to `out/entry.txt` with no trailing newline.
